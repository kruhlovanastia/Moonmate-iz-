### 🛡️ Рішення щодо Change Request (Забаганка замовника)
**Запит:** «Усі іконки на макеті втрачаються на фоні. Вставте кожну іконку всередині яскраво-фіолетового круга з неоновим зеленим розмитим сяйвом (Drop Shadow) навколо нього».

**Статус:** ❌ **Повністю відхилено.**

**Обґрунтування (Чому це недоцільно):**
1.  **Порушення айдентики бренду (UX/UI):** Яскраво-зелений неоновий колір вступає в жорсткий дисонанс із загальною містичною рожево-фіолетовою палітрою сайту. Це руйнує преміальне сприйняття продукту.
2.  **Візуальний шум та доступність (WCAG 2.1):** При великій кількості карток (на сторінці пошуку) зелені сяйва накладаються одне на одного, створюючи візуальний бруд. Це ускладнює зчитування інформації та викликає швидку втому очей.
3.  **Продуктивність (Core Web Vitals):** Використання великої кількості складних тіней (`drop-shadow`) одночасно створює надмірне навантаження на GPU пристроїв, що призводить до падіння FPS (лагів) при скролінгу, особливо на мобільних телефонах.
4.  **Проблема адаптивності:** На екранах смартфонів великі сяйва "з'їдають" корисний простір і роблять інтерфейс нечитабельним.

**Наше рішення (Компроміс):**
Замість зеленої забаганки ми вирішили початкову проблему замовника (втрату іконок на фоні) шляхом підвищення контрастності іконок та додавання легкого рожевого світіння (drop-shadow) при наведенні (hover). Це вирішує проблему UX, не ламаючи дизайн і не шкодячи продуктивності. У папці `Figma_Rejected_Mockup.png` додано макет із реалізованою забаганкою для наочного доказу її недоцільності.
